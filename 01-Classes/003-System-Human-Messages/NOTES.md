# Class Notes

## Message Objects

LangChain represents conversations using Message Objects.

Common message types:

- SystemMessage
- HumanMessage
- AIMessage

---

## SystemMessage

Purpose:

- Defines the AI's role.
- Sets behavior.
- Adds permanent instructions for the current conversation.

Example:

- You are a Python Instructor.
- Answer in simple English.
- Use bullet points.

---

## HumanMessage

Represents the user's actual request.

Example:

What is Python?

---

## AIMessage

Represents the response generated by the AI model.

`invoke()` returns an AIMessage object.

Example:

response.content

---

## invoke()

## Important Learning

SystemMessage has higher priority than HumanMessage.

However, this is **not a guarantee**.

Different models may behave differently.

Prompt Engineering requires testing and iteration.

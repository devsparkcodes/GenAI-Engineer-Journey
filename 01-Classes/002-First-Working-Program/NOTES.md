# Class 02 Notes

## 1. Environment Variables

Sensitive information like API Keys should never be hardcoded.

Store them inside:

.env

---

## 2. load_dotenv()

Loads all environment variables from the .env file.

```python
load_dotenv()
```

---

## 3. os.getenv()

Reads an environment variable.

```python
os.getenv("GROQ_API_KEY")
```

Returns the value of the variable.

---

## 4. ChatGroq

A LangChain class used to communicate with Groq-hosted language models.

```python
llm = ChatGroq(...)
```

Creates a ChatGroq object.

---

## 5. invoke()

Used to send a prompt to the model.

```python
response = llm.invoke("Hello")
```

Returns an AIMessage object.

---

## 6. AIMessage

The response returned by invoke() is not a string.

It is an AIMessage object.

---

## 7. response.content

Contains only the generated text.

```python
print(response.content)
```

---

## 8. Response Metadata

Contains extra information like:

- Token Usage
- Model Name
- Finish Reason
- Processing Time
- Provider Information

---

## 9. Token Usage

Prompt Tokens

Tokens sent to the model.

Completion Tokens

Tokens generated by the model.

Total Tokens

Prompt Tokens + Completion Tokens

---

## 10. Complete Flow

User Prompt

↓

invoke()

↓

LangChain

↓

Groq API

↓

LLM

↓

AIMessage Object

↓

response.content

↓

Terminal Output

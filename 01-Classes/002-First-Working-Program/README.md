# Class 02 - First Working GenAI Program

## Objective

In this class, we built and executed our first working Generative AI application using LangChain and Groq.

The main goal was to understand how an AI application communicates with an LLM through an API and how LangChain returns the response.

---

## Topics Covered

- Environment Variables (.env)
- python-dotenv
- load_dotenv()
- os.getenv()
- ChatGroq
- Creating an LLM Object
- invoke() Method
- AIMessage Object
- Response Object
- Response Metadata
- Token Usage
- response.content

---

## Learning Outcomes

After completing this class, I can:

- Create my first LangChain application.
- Load API keys securely using .env.
- Create a ChatGroq object.
- Send prompts using invoke().
- Understand the difference between a Response Object and Response Content.
- Read metadata returned by the model.
- Understand token usage.
- Explain the complete API request-response flow.

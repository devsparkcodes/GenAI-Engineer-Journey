# Class 04 - Prompt Templates

## Objective

In this class, we learned how to create dynamic and reusable prompts using LangChain's `PromptTemplate`.

Instead of hardcoding prompts every time, PromptTemplate allows us to define a template once and insert different values whenever needed.

---

## Topics Covered

- What is PromptTemplate?
- Why PromptTemplate is needed
- Hardcoded vs Dynamic Prompts
- Template Placeholders
- input_variables
- format() method
- Prompt generation flow

# Class 01 - First LangChain Program

## Objective

Learn the basic architecture of a LangChain application and understand how to communicate with an LLM using Groq.

## Topics Covered

- LangChain Overview
- ChatGroq Class
- Object Creation
- Constructor
- invoke() Method
- Response Object
- AIMessage
- response.content

## Learning Outcome

After completing this class, I can:

- Understand the purpose of LangChain.
- Create a ChatGroq object.
- Configure a model.
- Send prompts using invoke().
- Understand the difference between a response object and response content.
- Explain the complete high-level flow of an API call.

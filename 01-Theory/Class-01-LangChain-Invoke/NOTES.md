# Class 01 Notes

## LangChain

A framework used to build AI applications using Large Language Models.

---

## ChatGroq

A LangChain class used to communicate with Groq chat models.

---

## Object Creation

```python
llm = ChatGroq(...)
```

Creates a ChatGroq object.

---

## invoke()

invoke() sends a request to the LLM and returns an AIMessage object.

---

## Response Object

The response returned by invoke() is not a string.

It is an AIMessage object.

---

## content

The actual text generated by the model is stored inside:

response.content

---

## High-Level Flow

User
↓
Python
↓
LangChain
↓
Groq API
↓
LLM
↓
AIMessage
↓
response.content

# GenAI Engineer Journey

A structured, project-based journey of learning Generative AI Engineering through theory, hands-on practice, coding, documentation, and real-world projects.

## About This Repository

This repository documents my ongoing journey of learning Generative AI Engineering.

Instead of keeping my learning as disconnected notes and code snippets, I use this repository to organize what I learn, practice concepts, build projects, and document my progress.

The goal is to gradually move from Generative AI fundamentals to building practical AI applications involving Large Language Models (LLMs), APIs, RAG, AI agents, and other modern AI technologies.

This repository is also intended to be useful for other learners who want to follow a structured learning path and learn alongside the journey.

## Learning Goals

The main goals of this journey are to:

- Build a strong foundation in Generative AI
- Understand Large Language Models (LLMs)
- Learn effective Prompt Engineering
- Work with LLM APIs and SDKs
- Build applications with LangChain
- Understand and implement Retrieval-Augmented Generation (RAG)
- Learn AI Agents and tool-based workflows
- Build practical and production-oriented AI applications
- Document projects and learning outcomes
- Build a strong public AI engineering portfolio

## Learning Roadmap

The journey is organized into progressive stages:

1. AI & Generative AI Fundamentals
2. Prompt Engineering
3. LLM APIs and SDKs
4. LangChain
5. Retrieval-Augmented Generation (RAG)
6. AI Agents
7. Tool Calling and Integrations
8. Practical AI Projects
9. Deployment and Production Concepts

The roadmap may evolve as I learn and explore new technologies.
